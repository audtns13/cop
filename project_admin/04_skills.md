# 04. Skills — 기능별 사용 가이드

> 관리자·운영자가 시스템의 각 기능을 어떻게 사용하는지 정리한 문서입니다.

---

## 관리자 전용 기능

### 회원 승인
1. 사이드바 → **멤버 관리** 클릭
2. `승인 대기` 상태 회원 목록 확인
3. 해당 회원 행에서 **승인** 버튼 클릭
4. 상태 `PENDING` → `ACTIVE` 변경 (이후 로그인 가능)

### 회원 비밀번호 초기화
1. 멤버 관리 → 해당 회원 → **비밀번호 초기화** 클릭
2. 초기 비밀번호 `1234`로 리셋
3. 해당 회원에게 초기 비밀번호 안내 후 변경 요청

### 회원 삭제
1. 멤버 관리 → 해당 회원 → **삭제** 클릭
2. 삭제된 회원은 출결 현황·통계에서 자동 제외

---

## 활동기록 관리

### 새 활동 등록
1. **활동기록** 메뉴 → **작성** 버튼
2. 회의 날짜 / 제목 / 내용 입력
3. 파일 첨부 (선택) — 여러 개 가능
4. **저장** 클릭

### 파일 첨부 특이사항
- 파일은 **Base64로 DB에 직접 저장** (별도 스토리지 없음)
- 대용량 파일 업로드 시 Neon DB 용량(0.5GB) 주의
- 권장 파일 크기: 1개당 5MB 이하

### 활동기록 목록 표기
- 최신 날짜순 정렬 (meeting_dt 기준)
- 내용 120자 초과 시 **더보기** 버튼 자동 표시
- 참석자/전체인원 (%) 표기

---

## 출결 관리

### 출결 등록 방법 (일반 회원)
1. **출결 관리** 메뉴 → 해당 회차 확인
2. **참석** / **불참** 버튼 클릭
3. 등록 후 즉시 통계에 반영

### 출결 통계 확인
- 멤버별 출결률 (%) 표시
- 출결률 90% 이상 → `개근` 배지
- 출결률 80% 이상 → `우수` 배지
- 참석자 상세 보기 → 해당 회차 행 클릭 → 팝업 표시

---

## 점심 투표

### 투표 방법
1. **점심 메뉴** 메뉴 진입
2. 메뉴 선택 또는 직접 입력 또는 안먹음 선택
3. **투표** 클릭 (1회의당 1회만 가능)

### 관리자 메뉴 확정
1. 투표 결과 확인 후 확정 메뉴 선택
2. 대시보드 점심 투표 현황에 반영

## 자유게시판

| 기능 | 권한 |
|------|------|
| 게시글 조회 | 전체 회원 |
| 게시글 작성·수정·삭제 | 작성자 본인 + 관리자 |
| 파일 첨부 (최대 5개) | 작성자 본인 |
| 댓글 작성 | 전체 회원 |
| 공지 설정 (notice_yn=Y + 기간) | 작성자 본인 (게시글 작성/수정 시) |

### 수정 모드 파일 관리
- 수정 모드 진입 시 기존 첨부파일 목록 자동 표시
- 기존 파일 우측 X 버튼으로 개별 삭제 가능 (즉시 DB 반영)
- 파일은 기존 + 신규 합산 **최대 5개** 제한 (초과 시 저장 차단)

### 게시글 상세 글자 크기 조정
- 상세 페이지 우측 상단 **A−** / **A+** 버튼으로 글자 크기 조정 (10px ~ 22px)
- 선택한 크기는 `localStorage(cop_board_font)`에 저장되어 다음 방문 시 유지

---

## 공지 팝업

- 자유게시판 게시글 중 `notice_yn='Y'`이고 오늘 날짜가 공지 기간 내에 있는 최신 1건이 로그인 직후 팝업으로 표시
- 첨부파일이 있으면 팝업 하단에 파일 목록 표시 → 다운로드 버튼으로 즉시 다운로드 가능
- **오늘 하루 보지 않기** 체크 시 `localStorage(cop_hide_{postId}_{날짜})` 저장
  - 게시글 단위로 관리 → 새 공지 등록 시 기존 숨김과 무관하게 팝업 표시

## AI 챗봇 도우미

우측 하단 **로봇 아이콘(🤖) FAB 버튼**을 클릭하면 채팅 패널이 열립니다.

### 할 수 있는 것
| 기능 | 예시 질문 |
|------|-----------|
| 사이트 이용 안내 | "출결 등록 어떻게 해?" / "이 사이트 기능 알려줘" |
| 내 출결 조회 | "내 출결률 알려줘" / "나 몇 번 참석했어?" |
| 모임 일정 조회 | "다음 모임 언제야?" / "앞으로 예정된 모임 알려줘" |
| 점심 투표 현황 | "이번 점심 투표 현황 알려줘" |
| 최근 게시글 조회 | "자유게시판 최근 글 보여줘" |
| 출결 등록 | "다음 모임 참석으로 등록해줘" |

### 제한 사항
- 로그인 후에만 사용 가능
- 대화 히스토리는 페이지 새로고침 시 초기화 (DB 저장 안 함)
- 상단 **↺ 버튼**으로 대화 초기화 가능
- AI: Google Gemini 2.0 Flash (무료 1,500회/일 한도)
