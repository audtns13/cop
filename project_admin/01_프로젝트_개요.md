## 디렉토리 구조

```
cop-vercel/
│
├── public/
│   └── index.html          ← 전체 프론트엔드 (단일 파일 SPA)
│
├── api/                    ← Vercel 서버리스 함수 (파일 1개 = 엔드포인트 1개)
│   ├── auth.js             ← 로그인 / 로그아웃 / 회원가입
│   ├── users.js            ← 회원 목록·승인·삭제·비밀번호 초기화
│   ├── posts.js            ← 활동기록·자유게시판 CRUD
│   ├── comments.js         ← 댓글 CRUD
│   ├── attendance.js       ← 출결 등록·통계·요약
│   ├── files.js            ← 파일 업로드·다운로드·삭제
│   └── lunch.js            ← 점심 메뉴 투표
│
├── lib/                    ← 공통 유틸리티
│   ├── auth.js             ← JWT 서명·쿠키 설정·검증
│   ├── db.js               ← PostgreSQL 커넥션 풀
│   └── cors.js             ← CORS 헤더 처리
│
├── project_admin/          ← 프로젝트 관리 문서 (이 폴더)
├── schema.sql              ← DB 초기화 SQL
├── package.json            ← 의존성 정의
└── vercel.json             ← Vercel 라우팅 설정
```

## DB 테이블 구조

### `tb_user` — 회원
| 컬럼 | 타입 | 설명 |
|------|------|------|
| user_id | VARCHAR(20) PK | 사번 (영문+숫자 조합) |
| user_nm | VARCHAR(50) | 이름 |
| user_pwd | VARCHAR(255) | bcrypt 해시 비밀번호 |
| user_role | VARCHAR(10) | `ADMIN` / `USER` |
| status | VARCHAR(10) | `PENDING` / `ACTIVE` / NULL |
| reg_dt | TIMESTAMP | 가입일 |

### `tb_post` — 게시글
| 컬럼 | 타입 | 설명 |
|------|------|------|
| post_id | BIGSERIAL PK | 게시글 ID |
| post_type | VARCHAR(20) | `ACTIVITY` / `FREE` / `MEETING` |
| title | VARCHAR(200) | 제목 |
| content | TEXT | 본문 |
| writer_id / writer_nm | VARCHAR | 작성자 |
| meeting_dt | TIMESTAMP | 회의 날짜 (활동기록용) |
| view_cnt | INTEGER | 조회수 |
| notice_yn | VARCHAR(1) | 공지 여부 `Y`/`N` |
| notice_start_dt | TIMESTAMP | 공지 노출 시작일 (NULL=제한없음) |
| notice_end_dt | TIMESTAMP | 공지 노출 종료일 (NULL=제한없음) |

### `tb_attendance` — 출결
| 컬럼 | 타입 | 설명 |
|------|------|------|
| att_id | BIGSERIAL PK | |
| post_id | BIGINT | 연결된 활동기록 post_id |
| user_id | VARCHAR(20) | 회원 사번 |
| status | VARCHAR(10) | `Y`(참석) / `N`(불참) |
| UNIQUE | (post_id, user_id) | 1인 1회 출결 |

### `tb_file_info` — 첨부파일
| 컬럼 | 타입 | 설명 |
|------|------|------|
| file_id | BIGSERIAL PK | |
| post_id | BIGINT | 연결된 게시글 |
| orig_nm | VARCHAR(255) | 원본 파일명 |
| file_size | BIGINT | 파일 크기 (bytes) |
| file_data | TEXT | Base64 인코딩 파일 데이터 (DB 직접 저장) |

### `tb_lunch_vote` — 점심 투표
| 컬럼 | 설명 |
|------|------|
| user_id + meeting_post_id | UNIQUE — 회의 1회당 1인 1투표 |
| not_eating_yn | 안먹음 여부 |
| custom_yn | 직접 입력 여부 |
